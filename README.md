## Описание проекта
Автоматизированная информационная система для учёта финансовой деятельности гостиницы. Система позволяет:
- регистрировать заезды и выезды клиентов;
- вести учёт номерного фонда (вместимость, комфортность, цена, статус);
- автоматически рассчитывать стоимость проживания;
- формировать финансовую и статистическую отчётность;
- вести базу данных клиентов.

## Предметная область (кратко)
Гостиница предоставляет номера клиентам на определённый срок. Каждый номер имеет:
- вместимость,
- комфортность (люкс, полулюкс, обычный),
- цену.

Клиенты описываются ФИО и комментарием. При заезде фиксируется дата поселения, при выезде — дата освобождения.

## Функциональные требования (основные)
- Поиск свободных номеров по параметрам.
- Бронирование и заселение.
- Автоматический расчёт оплаты.
- Формирование отчётов: загрузка номеров, выручка за период, Occupancy Rate.
- Экспорт данных в 1С:Бухгалтерию (XML).
